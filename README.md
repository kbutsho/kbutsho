</a>

<p>
  <img src="https://img.shields.io/badge/Laravel-FF2D20?style=flat-square&logo=laravel&logoColor=white"/>
  <img src="https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white"/>

- Orders, FNSKU orders, inbound shipments, returns, SKU inventory and stores — each with its own workflow.

### ⛽ &nbsp;Fuel Distribution Monitoring System (FMS)

<a href="https://fms.gov.bd/login">
  <img width="100%" src="https://raw.githubusercontent.com/kbutsho/kbutsho/main/images/fms/fms-01.png" alt="FMS — Dashboard Overview"/>
</a>

<p>
  <img src="https://img.shields.io/badge/Laravel-FF2D20?style=flat-square&logo=laravel&logoColor=white"/>
  <img src="https://img.shields.io/badge/MySQL-4479A1?style=flat-square&logo=mysql&logoColor=white"/>
  <img src="https://img.shields.io/badge/Bootstrap-7952B3?style=flat-square&logo=bootstrap&logoColor=white"/>
  <img src="https://img.shields.io/badge/jQuery-0769AD?style=flat-square&logo=jquery&logoColor=white"/>
  &nbsp;<a href="https://fms.gov.bd/login"><img src="https://img.shields.io/badge/Live_Site-22C55E?style=flat-square&logo=googlechrome&logoColor=white"/></a>
</p>

- Role-based fuel tracking for **Admin, District Commissioner, Tag Officer and UNO**, each with its own dashboard.
- Company → depot → filling-station hierarchy, with dynamic assignment of Tag Officers to stations.
- **Date-locked daily reporting** (stock, supply, sales, variance) and analytics by district, upazila and depot.
- Running at national scale: **59 depots, 2,287 filling stations, 2,496 tag officers**.
